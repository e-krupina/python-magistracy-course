# Учебные задания по основам Python

Выполнила: Крупина Елизавета Иннокентьевна

В проекте представлены решения шести последовательных заданий по базовым возможностям Python — от простого вывода до функций и комбинирования коллекций.

## Выполненные задания

1. `task_01` — вывод приветствия с использованием переменных.
2. `task_02` — формирование и сортировка списка покупок.
3. `task_03` — обработка заявок приёмной комиссии.
4. `task_04` — подсчёт результатов спортсменов.
5. `task_05` — зрительское голосование на кинофестивале.
6. `task_06` — формирование чека и расчёт скидки.

## Использованные возможности Python

В работах используются строки, списки, кортежи, словари, множества, условия, циклы `while` и `for`, а также пользовательские функции.

## Запуск программ

Проект не требует установки сторонних пакетов. Необходим Python 3.12 или совместимая более новая версия.

Пример запуска из корня репозитория:

```powershell
python .\task_05\main.py
```

После запуска программа сама запрашивает необходимые входные данные.
